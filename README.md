🌀 Structural Cryptography Signature Demo
A quantum-resistant, interpretable signature system based on continuous resonance functions (instead of RSA/ECC). This demo uses frequency-based structural keys to generate and verify digital signatures via cosine-based modal functions.

🔐 Features
✅ Quantum-safe: No reliance on factorization or discrete logs

✅ Unique to each key: (Amplitude, Frequency, Phase) = personalized signature structure

✅ Explainable: Signature residuals and structure are observable and visualizable

✅ Implements:

Key generation from seed

Signature creation for a message

Signature verification

Residual (Δ) filtering and plotting

Pure Python implementation
